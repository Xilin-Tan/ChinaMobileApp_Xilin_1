# 待确认

> 最后更新：2026-11-18

这些问题没定之前不开始写功能代码。

## Q1. 企业微信里的报表，流向是哪个方向？

- [ ] 别人发给你，你来处理（→ 需要考虑"输入"）
- [ ] 你生成后要发出去（→ 只需要"输出"，群机器人即可）

## Q2. 手机端要做什么？

- [ ] 只在手机上看结果（→ 可能不需要 app，推图/PDF 到群即可）
- [ ] 要在手机上生成报表（→ 做 PWA 或原生 app）

## Q3. 报表最终交付形态是什么？

- [ ] PDF
- [ ] Excel
- [ ] 图片
- [ ] 网页
- [ ] 直接发到企业微信群里的消息

（可多选，需要排出优先级）

## Q4. 有没有真实样例？

- [ ] 一份原始 CSV（**列名和结构要真实**，数据可脱敏）
- [ ] 一份你手工作出的成品报表（Excel / PDF / 截图都行）

没有这两样，模板就无法定义。

## Q5. 是否有企业微信管理员权限？

- [ ] 是（→ 可以考虑自建应用、自动收文件）
- [ ] 否（→ 只能用群机器人，或手动放文件）

## Q6. 报表有几套？

- [ ] 只有一套固定模板
- [ ] 多套（需要说明分别是什么）
