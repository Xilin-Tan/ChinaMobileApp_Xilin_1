## 踩过的坑（重要，别再走一遍）

### 坑 1：`git` 命令找不到

**现象**：`无法将"git"项识别为 cmdlet`
**原因**：窗口是在安装 Git **之前**打开的，PATH 是旧的
**解决**：关掉所有 PowerShell 窗口，重新打开

### 坑 2：HTTPS 推送被重置

**现象**：`fatal: unable to access ... Recv failure: Connection was reset`
**原因**：当前网络对 `github.com:443` 的 HTTPS 连接做了干扰
**解决**：改用 **SSH over 443**
```
ssh://git@ssh.github.com:443/Xilin-Tan/ChinaMobileApp_Xilin_1.git
```
**已验证可用**，且 `ssh.github.com:443` 可达、握手正常。

### 坑 3：`Permission denied (publickey)`

**原因**：公钥没真正粘到 GitHub 上（`Set-Clipboard` 被终端选中的文字覆盖了）
**解决**：用记事本打开 `%USERPROFILE%\.ssh\id_ed25519.pub`，`Ctrl+A` `Ctrl+C`，再粘到
https://github.com/settings/ssh/new
**注意**：只贴 `.pub` 文件，绝不贴私钥。

### 坑 4：`dubious ownership`

**原因**：Codex 沙箱的 shell 用户与仓库所有者不同
**解决**：只读查询加 `git -c safe.directory=* ...`；写操作由用户在本机执行

### 坑 5：CSV 编码（尚未遇到，但一定会遇到）

中国版 Excel 导出的 CSV 多为 **GBK**，按 UTF-8 读会乱码。
实现时必须自动探测编码，不要默认 UTF-8。

### 坑 6：写回 xlsx 时 `RemoveAll()` 会毁掉格式

**现象**：输出文件里所有单元格的 `r`（坐标）和 `s`（样式）属性都没了，整张表变成白板
**原因**：`XmlNode.RemoveAll()` 连属性一起清空
**解决**：只 `RemoveChild` 掉 `f`/`v`/`is` 三个子节点，属性必须保留

### 坑 7：原模板的 `fullCalcOnLoad="1"`

**现象**：输出文件在 Excel 里打开后进度条卡很久
**原因**：原模板让 Excel 打开时全量重算
**解决**：输出时删掉这个属性，我们已把结果写成缓存值

## 机器层面的问题（与本项目无关，但建议处理）

### 1. F 盘（外接机械硬盘）文件系统损坏 —— 最值得优先处理

**现象**：每次开机都记一条

```
卷 F: (\Device\HarddiskVolume8) 需要脱机一段时间以执行错误修复。
请运行 "CHKDSK /SPOTFIX" 或 "REPAIR-VOLUME F:"
```

**时间线**：最早 **2026-04-26** 就有，**每天开机必现**，已经持续半年多。

**含义**：F 盘被标记为 dirty，NTFS 发现了卷结构异常但一直没修。
这不影响本项目（我们用 C 盘），但 F 盘标签是「外接机械移动硬盘」，
机械盘 + 长期不修 = 数据风险。

**处理**（需要管理员 PowerShell，全程只读修复、不动数据）：

```powershell
Repair-Volume -DriveLetter F -Scan
```

先扫描看报告。如果提示需要修，再执行：

```powershell
Repair-Volume -DriveLetter F -SpotFix
```
