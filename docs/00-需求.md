# 需求与范围

> 最后更新：2026-11-18

## 一句话

把固定结构的报表数据（CSV/Excel），在本地自动转成固定模板的可视化报表。

## 痛点（用户实际经历）

- 每次都要重新向 AI 描述"我要什么样的报表"
- 生成慢，要等很久
- 消耗大量 token
- 每次结果可能不一致，难以复现

## 关键洞察

报表**结构始终固定，只有数据变化** → 这属于确定性转换，不需要 AI。

## 功能设想（待细化）

1. 导入 CSV/Excel：拖入文件 或 监听某个文件夹
2. 按固定规则计算指标、分组、聚合
3. 渲染：表格 + 图表 + 结论文字
4. 导出：PDF / Excel / 图片 / 网页
5. 可选：推送到企业微信群机器人

## 平台目标

- 第一优先：**Windows 桌面**（日常真正使用的场景）
- 兼顾：安卓 / 苹果手机
- 手机端真实诉求**待确认**：在手机上要"生成"报表，还是只要"查看"结果？
  - 如果只是查看 → 可能完全不需要手机 app，推图片/PDF 到群即可

## 企业微信的角色（未定，三种可能）

| 方案 | 难度 | 前提 |
|---|---|---|
| 只做**输出**：群机器人 webhook 推送 | 低 | 建个群机器人即可，无需审批 |
| 只做**输入**：自动读取群里的文件 | 高 | 需企业管理员 + 会话存档（认证/付费）或自建应用 |
| **不做 API**：用户手动把文件放进本地文件夹 | 零 | 无需任何权限，立即可用 |

倾向：先做第三种，稳定后再考虑接入 API。

## 合规提醒

报表若含业务敏感数据，推送到企业微信群会经过腾讯服务器。建议推摘要，不推明细。

## 明确不做

- 主流程里调用大模型（可选的"文字解读"另说，不进主链路）
- 通用 BI 工具：只服务这一种固定报表
- 多用户 / 权限体系
